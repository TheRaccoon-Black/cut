Topologi Mesh

Apa itu Topologi Mesh?

Topologi Mesh adalah konfigurasi jaringan dimana setiap node terhubung langsung ke semua node lainnya.

Rumus Topologi Mesh

Jumlah Tautan = N × (N - 1) / 2

Kelebihan:

  • Redundansi Tinggi: Banyak jalur antara dua node
  • Toleransi Kesalahan: Jaringan bertahan dari kegagalan tautan
  • Jalur Pendek: Koneksi langsung 1 hop antar node

Kekurangan:

  • Biaya: Membutuhkan banyak kabel/port
  • Skalabilitas: Tidak praktis > ~100 node

Algoritma Johnson

Apa itu Johnson?

Algoritma Johnson mencari jalur terpendek antara semua pasangan vertex dalam satu eksekusi.

Ditemukan oleh: Donald B. Johnson (1977)

Keunggulan: Lebih efisien dari Bellman-Ford untuk all-pairs shortest path!

Langkah-langkah Johnson

1

Tambah Vertex Semu (Q)

Tambahkan vertex semu Q yang terhubung ke semua vertex lain dengan bobot 0.

Graf sekarang memiliki V+1 vertex.

2

Jalankan Bellman-Ford dari Q

Dari vertex Q, jalankan Bellman-Ford untuk menghitung bobot reweighting.

Hasil: h(v) untuk setiap vertex v.

3

Reweighting Bobot

Hitung bobot baru: w'(u,v) = w(u,v) + h(u) - h(v)

Semua bobot baru menjadi non-negatif!

4

Jalankan Dijkstra dari Setiap Vertex

Karena bobot non-negatif, gunakan Dijkstra (lebih cepat!)

Jalankan dari setiap vertex untuk dapat semua pasangan jalur.

Pseudocode

function Johnson(Graph): // Langkah 1: Tambahkan vertex semu Q Tambah Q ke Graph Untuk setiap v: tambahkan edge (Q, v) dengan bobot 0 // Langkah 2: Bellman-Ford dari Q h = BellmanFord(Graph, Q) Jika h berisi negatif cycle: return error // Langkah 3: Reweighting Untuk setiap edge (u, v) dengan bobot w: w'(u, v) = w(u, v) + h(u) - h(v) // Langkah 4: Dijkstra dari setiap vertex Untuk setiap vertex s: Jalankan Dijkstra(Graph, s) dengan bobot w' Konversi kembali ke bobot asli return all_pairs_shortest_paths

Implementasi Controller

Arsitektur

JohnsonMeshController memiliki komponen utama:

  • Topology Monitor: Menemukan switch/tautan setiap 20 detik
  • Johnson Calculator: nx.johnson() di thread latar belakang
  • Gatekeeper: Memblokir lalu lintas selama boot
  • Packet Handler: Memproses paket masuk

Perbedaan dengan Bellman-Ford Controller

Aspek Bellman-Ford Johnson

Lock Time ~700 detik (mesh 50) ~400 detik (mesh 50)
Efisiensi O(V² × E) O(V² log V + V × E)

Kuis

1. Berapa jumlah tautan di mesh 10 node?
A. 10
B. 45
C. 90
D. 100
Benar! Rumus: N × (N-1) / 2 = 10 × 9 / 2 = 45
2. Apa keunggulan Johnson dibanding Bellman-Ford?
A. Lebih sederhana
B. Lebih efisien untuk all-pairs
C. Mendukung bobot negatif
D. Hasil berbeda di mesh
Benar! Johnson O(V² log V + VE) lebih cepat dari BF O(V² × E).
3. Di mesh, jalur Johnson vs Bellman-Ford?
A. Sama (1 hop langsung)
B. Johnson lebih panjang
C. Bellman-Ford lebih pendek
D. Bergantung algoritma
Benar! Di mesh terhubung lengkap, keduanya menemukan jalur 1-hop.
4. Apa langkah pertama Johnson?
A. Tambahkan vertex semu Q
B. Jalankan Dijkstra
C. Hitung semua pasangan
D. Reweighting langsung
Benar! Johnson menambahkan vertex semu Q untuk reweighting.
5. Kompleksitas Johnson untuk all-pairs?
A. O(V)
B. O(V × E)
C. O(V² log V + V × E)
D. O(V² × E)
Benar! O(V² log V + VE) lebih efisien dari O(V² × E).
